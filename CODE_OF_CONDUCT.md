# Code of conduct

## The short version

Be civil. Assume the other person is trying to get something right.
Disagree about the work, not about the person doing it.

## What is expected

- Give feedback on code, measurements and reasoning. "This rule fires on
  lru-cache and here is why that is wrong" is useful. "This is obviously
  broken" is not.
- Accept that a maintainer may decline a change. A security tool gets worse
  when it accumulates rules nobody measured.
- Report a finding once. Reopening the same argument under a new issue
  wastes everyone's time, yours included.

## What is not

Harassment, personal attacks, discrimination on any basis, publishing
someone's private information, or sustained disruption of a discussion.

## Enforcement

Report to martins.victor212004@gmail.com. Reports are read by the
maintainer and kept private. The response is proportionate: usually a
request to stop, then removal of the comment, then a block.

Security vulnerabilities in capsurface itself are not a conduct matter and
go through [SECURITY.md](SECURITY.md) instead.
